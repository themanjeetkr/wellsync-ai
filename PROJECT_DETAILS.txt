1. EXECUTIVE SUMMARY & CORE VISION
================================================================================

WellSync (also branded within modules as MindScribe) is a modern full-stack, 
privacy-first digital wellness and mental health companion. It is specifically
engineered to bridge the critical gap between emotional mental health and 
physical physiological nutrition.

Modern health platforms almost always isolate mental health from physical health:
users track workouts/calories in one app, and write notes or talk to therapists in 
another. WellSync reconciles both domains into a single cohesive platform.

THE CORE PREMISE:
- What you feel impacts how and what you eat (emotional eating, loss of appetite, stress cravings).
- What you eat impacts your emotional equilibrium, energy, and stress resilience.
- By combining automated AI emotional sentiment analysis of personal journals with
  natural-language dietary intake logging, WellSync offers deep self-awareness 
  and actionable reflective guidance.

CLINICAL & ETHICAL DISCLAIMER:
WellSync is strictly an introspective mindfulness and self-care platform. It is 
not a clinical diagnostic device, medical instrument, or substitute for 
professional psychiatric, psychological, or dietary counsel. Built-in heuristics
monitor for severe distress indicators and provide non-judgmental prompts.

2. WHAT THE PROJECT DOES (FEATURES & FUNCTIONALITY)
================================================================================

--------------------------------------------------------------------------------
2.1. SMART AI-POWERED EMOTIONAL JOURNALING
--------------------------------------------------------------------------------
- Rich Personal Journaling: Users write free-form daily journal entries with titles,
  detailed text content, mood selectors, and custom thematic tags.
- Automated Emotion Classification: When an entry is analyzed or saved, the text 
  is processed through a Hugging Face Natural Language Processing (NLP) pipeline.
  It classifies the dominant emotion into categories:
  * Joy / Happiness
  * Sadness
  * Anger / Frustration
  * Fear / Anxiety
  * Surprise
  * Calm / Neutral
- Multi-Tier Emotion Resolution: Combines keyword heuristic patterns, confidence
  scoring, entry word count, and transformer model probabilities to accurately
  determine whether the entry is joyful, anxious, sad, angry, calm, or neutral.
- Empathetic AI Feedback Generation: Rather than generic automated replies, the 
  engine constructs tailored psychological prompts:
  * For Anger: Grounding prompts, breathing exercises, and boundary reflections.
  * For Sadness: Compassionate self-soothing, identifying specific distress triggers.
  * For Anxiety: Identifying controllable vs. uncontrollable factors and micro-steps.
  * For Joy/Excitement: Capturing positive triggers to foster gratitude habits.
- Live AI Assistant in Editor: While composing an entry (minimum 20 characters), 
  users can click "Get AI Reflection" to preview detected emotions, recommendations, 
  and supportive guidance before committing the entry to the database.
- Complete CRUD Operations: Entries can be created, viewed in detail, edited, 
  searched, filtered, and deleted.

--------------------------------------------------------------------------------
2.2. MOOD ANALYTICS & PSYCHOLOGICAL INSIGHTS
--------------------------------------------------------------------------------
- Emotional Balance Radar Chart: Visualizes the multi-axis distribution of the user's
  emotional spectrum across Joy, Calm, Focus, Anxiety, Sadness, and Anger using 
  Recharts polar coordinate radar diagrams.
- Mood Distribution Breakdown: Interactive donut and pie charts representing the 
  exact percentage of moods logged over the user's journaling lifecycle.
- Weekly Reflection Timeline: Area charts showing day-by-day emotional scores (from 
  scale 2 for Anger up to 10 for Excitement) alongside entry frequency bars.
- Pattern Recognition & Habit Cards:
  * Emotional Equilibrium: Evaluates when calmness peaks during the week.
  * Habit Momentum: Tracks streak consistency and reflection count.
  * Actionable Guidance: Delivers dynamic mindfulness recommendations (e.g. 3-point
    gratitude scan, evening wind-down journaling).

--------------------------------------------------------------------------------
2.3. INTELLIGENT NUTRITION & MEAL ANALYZER
--------------------------------------------------------------------------------
- Natural Language Input: Users do not need to search tedious databases item by item
  or weigh food in grams. They simply enter meal text in plain conversational English:
  Example: "2 bananas, 1 glass milk, 1 bowl oatmeal, 2 boiled eggs".
- Automated Unit & Quantity Parsing: Regex algorithms parse quantities, fractions 
  (e.g., "1/2"), and common volume units (cup, bowl, glass, tbsp, tsp, piece, slice, 
  serving) to calculate individual portion multipliers.
- Live Macronutrient Extraction: Connects to the USDA FoodData Central API to fetch
  exact nutritional profiles:
  * Total Calories (kcal)
  * Protein (grams)
  * Carbohydrates (grams)
  * Total Fat / Lipids (grams)
  * Dietary Fiber (grams)
- Aggregated Daily & Weekly Metrics:
  * Today's Nutrient Summary: Real-time progress cards against standard dietary targets.
  * 7-Day Rolling Calorie Trend: Daily area chart of caloric intake.
  * 4-Week Trajectory: Weekly aggregated intake patterns.
- Persistent Meal Logging: Users can review their full meal history and delete records.

--------------------------------------------------------------------------------
2.4. AUTHENTICATION, USER MANAGEMENT & SECURITY
--------------------------------------------------------------------------------
- Secure User Registration & Login: Standard email/password onboarding.
- Password Hashing: Uses bcryptjs with 10 salt rounds before saving to MongoDB.
- Stateless Session Tokens: Issues signed JSON Web Tokens (JWT) with a 24-hour TTL.
- Account Management: Users can update their display name, email address, and 
  securely change their password (with current password verification).
- Route Protection: Frontend ProtectedRoute components prevent unauthorized access,
  automatically redirecting unauthenticated visitors to the login view.
- Security Headers: Express backend utilizes Helmet to configure Content Security 
  Policies, anti-XSS filters, clickjacking prevention, and MIME sniffing protection.
- CORS Policies: Configured to support local development and production domains.

3.5. AI / NLP EMOTION DETECTION & REFLECTION ENGINE
--------------------------------------------------------------------------------
The file Backend/utils/aiAnalysis.js contains the intelligent processing logic:

Step 1: Text Preprocessing & Keyword Heuristics
  The engine cleans input text and first evaluates explicit emotional indicators:
  - Anger: ["angry", "mad", "rage", "furious", "fight", "hit", "hate", "irritated"]
  - Sadness: ["sad", "cried", "cry", "lonely", "depressed", "hopeless", "hurt", "broken"]
  - Fear/Anxiety: ["scared", "afraid", "anxious", "worried", "panic", "nervous", "stressed"]
  - Joy: ["happy", "excited", "proud", "grateful", "great", "awesome", "achieved"]

Step 2: Hugging Face Deep Learning Inference
  The text is transmitted to Hugging Face Inference API running:
  Model: `j-hartmann/emotion-english-distilroberta-base`
  The model evaluates contextual semantic patterns and scores emotions across:
  [joy, sadness, anger, fear, surprise, neutral].

Step 3: Multi-Tier Mood Resolution (resolveJournalMood)
  1. If clear emotional keywords exist, prioritize them to respect explicit user words.
  2. If the user explicitly picked a manual mood, and entry is short (< 12 words) 
     or model confidence is below 65%, honor user selection.
  3. Otherwise, adopt the transformer model's highest-probability prediction.

Step 4: Empathetic Reflection Construction (buildJournalSuggestions)
  Generates targeted, supportive advice and dynamic reflection prompts:
  * Encourages gratitude scanning if no gratitude terms were used.
  * Suggests actionable 10-minute micro-steps if negative emotions are detected.
  * Prompts the user to capture success strategies when joy or calm is detected.

--------------------------------------------------------------------------------
3.6. NUTRITION NLP TEXT PARSER & USDA FOODDATA CENTRAL INTEGRATION
--------------------------------------------------------------------------------
The file Backend/services/usdaService.js drives natural language food tracking:

Step 1: Line-by-Line Parsing (parseMealLine)
  Splits user text by newline or comma. Uses regex:
  /^(\d+(?:\.\d+)?|\d+\/\d+)\s+(.+)$/
  - Matches numbers (e.g. "2") or fractions (e.g. "1/2").
  - Identifies food descriptions while stripping redundant unit keywords 
    (cup, bowl, glass, tbsp, tsp, piece, slice, serving).

Step 2: USDA Search Query (searchFood)
  Sends food query to USDA FoodData Central endpoint:
  https://api.nal.usda.gov/fdc/v1/foods/search
  Fetches official USDA food nutrients using exact alias mappings:
  - Calories: "Energy", "Energy (Atwater General Factors)"
  - Protein: "Protein"
  - Carbohydrates: "Carbohydrate, by difference"
  - Fat: "Total lipid (fat)"
  - Fiber: "Fiber, total dietary"

Step 3: Scaling & Aggregation
  Multiplies base 100g or serving nutrients by the parsed quantity multiplier.
  Sums all individual ingredients into total meal macros:
  Calories, Protein, Carbohydrates, Fat, and Fiber.

Step 4: MongoDB Aggregation Pipeline
  Uses MongoDB $match and $group aggregation operators to calculate the user's
  real-time cumulative daily intake from 00:00:00 to 23:59:59.

--------------------------------------------------------------------------------
3.7. PAYMENT VERIFICATION ARCHITECTURE (RAZORPAY HMAC-SHA256)
--------------------------------------------------------------------------------
- Razorpay Orders: When a user selects a plan, Backend/controllers/paymentController.js
  initiates an order with the amount in paise (e.g., ₹299 = 29900 paise).
- Cryptographic Signature Verification:
  Upon checkout completion, Razorpay returns:
  * razorpay_order_id
  * razorpay_payment_id
  * razorpay_signature
  The server recomputes the expected signature:
  HMAC_SHA256(razorpay_order_id + "|" + razorpay_payment_id, RAZORPAY_KEY_SECRET)
  If the generated hex digest matches razorpay_signature, payment validity is guaranteed.
- Database Ledger: Successful payments are stored in the Payment collection with
  status 'paid', timestamp, and plan identifier.

  cd "AI mental Health care"

  cd Backend
  npm install
  # Ensure .env is populated with credentials
  npm run server
  # Server will listen on http://localhost:5000

Step 3: Start Frontend Client
  # In a new terminal window:
  cd Frontend
  npm install
  npm run dev
  # Application will be accessible at http://localhost:5173

10. PRODUCTION DEPLOYMENT STRATEGY
================================================================================

FRONTEND DEPLOYMENT (e.g. Vercel, Netlify, Cloudflare Pages):
1. Root Directory: `Frontend`
2. Build Command: `npm run build`
3. Output Directory: `dist`
4. Environment Variables:
   - `VITE_API_BASE_URL` = https://ai-integrated-mental-health-journal.onrender.com/api
5. SPA Rewrite Rule:
   Ensure all routes rewrite to `index.html` for React Router 7 compatibility.

BACKEND DEPLOYMENT (e.g. Render, Railway, AWS EC2):
1. Root Directory: `Backend`
2. Build Command: `npm install`
3. Start Command: `npm start`
4. Environment Variables:
   - `PORT` = 5000 (or platform assigned)
   - `MONGO_URI` = your production MongoDB Atlas cluster URI
   - `JWT_SECRET` = high-entropy 256-bit secret string
   - `HUGGINGFACE_API_TOKEN` = Hugging Face production token
   - `USDA_API_KEY` = USDA FoodData API key
   - `RAZORPAY_KEY_ID` & `RAZORPAY_KEY_SECRET` = Live or test Razorpay keys

DATABASE (MongoDB Atlas):
- Network Access: Whitelist IP addresses of the hosting platform (or 0.0.0.0/0 with strict authentication).
- Enable automated daily backups and index monitoring.
